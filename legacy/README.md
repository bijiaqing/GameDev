# Swarm legacy snapshots

This directory preserves the two standalone swarm implementations that preceded the merged
fluid–swarm project

- `swarm_before_audit/` is the original historical snapshot retained before the swarm numerical audit
- `swarm_after_audit/` is the corrected and renamed standalone swarm tree immediately before promotion of the merged project

The active code is at the repository root under `inc/`, `src/`, `mod/`, and `tst/`
